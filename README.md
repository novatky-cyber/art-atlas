# Art Atlas — 自分の美術手帳

美術館で見た作品を記録する、自分専用の美術手帳です。作品データベースは、記録を支える「教科書」として、
様式・作家・美術館・時代・テーマ・用語でつながっています。

公開URL：https://novatky-cyber.github.io/art-atlas/

## できること
- **美術手帳**：作品ページの「見た！」から記録（鑑賞日・美術館・感想・感動度★・気分タグ・自分の写真）。一覧は新しい順／美術館別／年別
- **チェックイン**：現在地から近くの美術館を選ぶと、その間の記録に日付と美術館が自動で入る
- **クイック登録（＋）**：作品写真と解説プレートの写真を撮るだけで保存 → 夜間に AI が作品を特定して解説ページを作成（解説待ち／要確認／完成）
- **作品ページ**：番号付き注釈（位置は手帳から微調整可）、物語と時代背景、どこで見られるか、作者、技法、様式の見分け方、豆知識
- **つなぐ**：様式・作家・美術館/都市・時代・地域・テーマ特集（宗教と美術／光の表現／権力と建築／人体表現／自然と庭）・用語集（本文から自動リンク）
- **美術年表**：縦に時代、横に地域。見た作品に印
- **毎晩の自動処理**：記録の解説 → 作品50点の追加（日本以外の不足地域を優先）→ 公開

## 仕組み
- 静的サイト（Vite + React + TypeScript / PWA）を GitHub Actions でビルドし GitHub Pages に公開
- 手帳のデータと写真は Supabase（本人だけが読み書きできる設定）
- 作品の事実データは美術館のオープンアクセス API（Met / シカゴ美術館 / クリーブランド美術館 / Smithsonian）と Wikidata・Wikimedia Commons から取得。画像は出典URLを参照
- 解説文は AI 生成（画面に「AI生成」と表示）

開発者向けの詳細は `CLAUDE.md` を参照してください。
